# Cidade Viva — Jogo2

Protótipo de jogo 3D em terceira pessoa inspirado em jogos de mundo aberto urbano.

## Já implementado

- Personagem principal em terceira pessoa
- Câmera orbitável e zoom
- Pistola com raycast e dano
- Carros que podem ser dirigidos
- NPCs com necessidades (fome, social, medo)
- NPCs que passeiam, procuram companhia e fogem de perigo
- Relações entre NPCs
- Memórias de encontros e eventos perigosos
- Memórias persistidas no `localStorage`
- Inspetor de memória dos NPCs
- Controles para teclado/mouse e botões básicos para telas touch

## Controles

- `WASD`: mover / dirigir
- `Shift`: correr
- Botão direito + arrastar: girar câmera
- Scroll: zoom
- Clique esquerdo: atirar
- `E`: entrar/sair de carro
- `Q`: visualizar memória do NPC próximo

## Tecnologia

Protótipo estático em HTML/CSS/JavaScript com Three.js, preparado para rodar diretamente no navegador e ser publicado pelo GitHub Pages.
